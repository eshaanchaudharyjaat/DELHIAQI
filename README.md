# Delhi Air Quality (AQI) Analysis and Visualization

A Python mini project that cleans, analyses and visualizes Delhi's air quality
data using pandas, numpy, matplotlib and seaborn.

**Author:** Eshaan Chaudhary
**Course:** BCA (Data Science), 3rd Semester, Chandigarh University

---

## Features
- Loads AQI data from a CSV file and cleans it (date parsing, missing values)
- Fills missing values with the median of the same month (keeps seasonality)
- Classifies every day into CPCB AQI categories (Good to Severe)
- Finds the most polluted and cleanest months and years
- Compares pollutants (PM2.5, PM10, NO2, SO2, CO, O3)
- Shows which pollutant is most correlated with AQI
- Saves 6 charts automatically

## Installation and usage
```bash
git clone https://github.com/<your-username>/delhi-aqi-analysis.git
cd delhi-aqi-analysis
pip install -r requirements.txt
python aqi_analysis.py
```
Charts are saved in `charts/` and the key findings are printed in the terminal.

## Dataset
**Note:** the `data/delhi_aqi.csv` included in this repository is **sample data
generated by the program** so the project runs out of the box. It imitates
Delhi's seasonal pattern but is not real measurement data, so the charts and
findings shown here are only a demonstration.

To analyse real data:
1. Download `city_day.csv` from the Kaggle dataset
   *"Air Quality Data in India (2015 - 2020)"*.
2. Rename it to `delhi_aqi.csv` and place it in the `data/` folder.
3. Run `python aqi_analysis.py` again. Rows for Delhi are filtered automatically.

Expected columns: `Date, PM2.5, PM10, NO2, SO2, CO, O3, AQI`
(a `City` column is also handled).

## AQI categories (CPCB, India)
| AQI | Category |
|---|---|
| 0-50 | Good |
| 51-100 | Satisfactory |
| 101-200 | Moderate |
| 201-300 | Poor |
| 301-400 | Very Poor |
| 401+ | Severe |
